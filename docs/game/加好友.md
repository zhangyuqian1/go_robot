# 加好友
## c_add_social_1
```
//aid 为角色id
系统模块:14，协议名称:c_add_social_1
{
  "aid": 16783880,
  "protobufBody": "c_add_social_1",
  "type": 1
}
```

## s_social_list_1（响应）
系统模块:14，协议名称:s_social_list_1，与 `c_add_social_1` 同消息号。

`type` 取值对应 `SocialRelation`：
- `0` = `SOCIAL_APPLY` 申请
- `1` = `SOCIAL_FRIEND` 好友
- `2` = `SOCIAL_BLANK` 黑名单

加好友成功会下发好友列表 `s_social_list_1`（`list` 每项含 `basic.aid` / `social` / `offline_time` / `sid`），回包缓存到 `GameClient.FriendIDList`。

## 压测案例 Friend
案例名 `Friend`（加好友）：`RobotInit` 登录完成后，在 `--friend-rate` 边界内持续向目标角色发送 `c_add_social_1`（`type=1`）。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--friend-rate` | 1 | 加好友限流阈值 |
| `--friend-aid` | 16783880 | 目标好友角色 id |
