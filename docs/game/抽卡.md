| 消息文件名    | 模块名    | 说明                                    |

| `0.default`   | 默认/控制 | 登录角色、心跳、进出场景、实体创建/移除 |
| `1.movement`  | 移动      | 角色移动同步                            |

| `9.equip`     | 装备      | 装备打开、穿戴、出售                    |
| `15.misc`     | 杂项      | 游戏设置                                |
| `16.observer` | 观察者    | 怪物出现、实体视野变化                  |
| `19.pet`      | 宠物      | 宠物出战、信息、移除                    |
| `101.arena`   | 竞技场    | 竞技场信息、列表、挑战、结果            |
