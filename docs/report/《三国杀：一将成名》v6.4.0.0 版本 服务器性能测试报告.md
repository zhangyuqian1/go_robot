## 需求概述

《星火英雄》计划于7月22日进行不删档付费测试，期望单服PCU为200。需进行如下测试：

1. 单场景测试：验证创角、登录、主城移动、野外战斗、首领魂卡、深渊副本玩法的性能是否达标。
2. 容量测试
3. 稳定性测试

## 测试结论

测试结论： 中风险

概述：本次测试共发现1个问题（详见问题列表）

1. 神威大乱斗匹配测试中，AI服务存在负载不均衡的问题，评估为低风险。
2. 刮刮乐、武将置换、登录等功能，相关协议的TP90耗时处于基线标准内，服务器负载不高于70%，符合基线标准，性能无风险。
3. 群英绘卷10连抽场景最高可支持4千并发协议成功率100%、TP90响应耗时1秒以内且无显著性能问题。
